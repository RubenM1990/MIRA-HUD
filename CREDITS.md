[21st.dev](https://21st.dev/community/components):

- **Animated shader background** - `components/ShaderBackground.jsx` (the WebGL wave backdrop, tinted violet here).

Both are used under the MIT license, which permits reuse (including commercial) provided
attribution is kept - hence this file. If you fork MIRA-HUD, please keep this attribution.

[open-meteo](https://open-meteo.com) (free, no key).

Everything else (the field, the ring, the light lines, the particle core, the status bar and
the app wiring) is original to this project.
